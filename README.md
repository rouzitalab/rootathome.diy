# rootathome.diy

Coming-soon site for [root@home](https://github.com/rouzitalab/rootathome) — self-hosted household media.

## Local preview

```bash
python3 -m http.server 4173
```

Open [http://127.0.0.1:4173](http://127.0.0.1:4173).

## Deploy

Point the domain at any static host (GitHub Pages, Cloudflare Pages, Netlify). Serve the repo root; `index.html` is the entry.
